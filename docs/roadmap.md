## 0.2.2 背景与暂停

- 主页面/游戏内照片背景：拖入图片 → 裁切器 → 平移/缩放 → 保存。
- 支持 JPG、PNG、WebP、AVIF、GIF、BMP、SVG、HEIC/HEIF（HEIC 使用 WASM 转换）。
- 背景图与裁切结果存入 IndexedDB，重启后仍生效。
- 游戏内按 Esc 使用捕获阶段监听，唤出暂停菜单：继续 / 重试 / 返回主页面 / 选曲；再按 Esc 继续。
- 游戏内拖入照片会自动暂停并打开裁切器。
- 选曲页新增「主页」按钮。
- 设置 → 显示与声音新增主页面背景/游戏背景控制。

## 0.3.0 输入与琴键布局

- 设置新增「输入方式」：键盘（横向琴键）/ 触摸屏（八区多点）。
- 设置新增「音符方向」：从上往下 / 从下往上，键盘琴键模式生效。
- 键盘模式：8 个扇区按 A S D F J K L ; 展开成横向琴键，键位列在屏幕中下部（反向模式在中上部），音符落向判定线。
- 触摸屏模式：保留八扇区圆环，八个扇区都是可多点触控的命中区；支持同时按下多个扇区。
- Windows 触控板在 Electron 中只暴露单鼠标指针，无法取得八指触控；本轮不做原生 HID，触控板可作为单指针回退（点击/拖动）。
- 新增输入模式浏览器回归测试与设置校验，单元测试 55 个。

## 0.2.8 特殊路径 IPC 修复

- 修复安装/解压路径含 `#`、`%`、空格或非 ASCII 时，文件 URL 编码不一致导致 `untrusted IPC sender`、内容无法加载的问题。
- IPC 改为校验主窗口 `WebContents` 与主 frame 身份，不再依赖脆弱的 URL 字符串比较。
- 仍拒绝子 frame、外部窗口和不可信来源。

## 0.2.7 启动错误处理

- 背景 IndexedDB 打开异常不再阻断启动；损坏/只读存储只影响背景功能。
- 启动/开始游戏错误写入 `user-data/startup-error.log`（安装版在 `%APPDATA%/maimai-key`）。
- 错误页增加版本号和「复制错误信息」，方便反馈。
- 单元测试仍为 53 个。

## 已知限制

- 自动打谱是草稿生成器；复杂编曲的 BPM 可能需手动覆盖。
- 平台 DRM 加密缓存（NCM/QMC/MFLAC/MGG/KGM/KWM…）**不支持也不解密**。
- WMA/APE/AIFF 音频需先转成 MP3/FLAC；TIFF 图片需先转成 JPG/PNG/WebP。
- GIF 背景使用第一帧，不支持动态背景。
- 曲包导入以 zip 为主；未解压的 maidata 文件夹不会自动转换。
- 没有练习模式、曲库管理器、回放列表；仅中文。
