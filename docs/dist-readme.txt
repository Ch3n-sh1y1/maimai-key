MaimaiKey 0.3.1 — 键盘/触摸版舞萌（Windows x64）
================================================

一个支持键盘/触摸屏的 maimai 风格节奏游戏。内置原创占位曲，
不包含任何 SEGA 版权素材；与 SEGA 无关联。

------------------------------------------------
一、启动（3 步）
------------------------------------------------

1. 把整个压缩包解压到任意目录（建议路径不含特殊符号）。
   注意：不要直接在压缩包里双击运行，也不要只复制 MaimaiKey.exe，
   它需要同目录下的 resources、locales、art 等文件。

2. 双击 MaimaiKey.exe。

3. 如果 Windows 提示“Windows 已保护你的电脑”或“未知发布者”：
   点“更多信息” → “仍要运行”。
   本程序未购买代码签名证书，属于正常提示。

首次启动会初始化音频/渲染，并把内置占位曲复制到曲库（约 8MB）。
系统要求：Windows 10/11 64 位、支持 WebGL 的显卡、可用音频输出、键盘或触摸屏
（推荐支持 N-Key Rollover 的键盘）。

------------------------------------------------
二、0.2.x 新增
------------------------------------------------

- 音频自动打谱：MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WebM → 自动测 BPM 和重音 → 生成
  Basic / Advanced / Expert / Master 四张可玩谱面；可直接编辑 Simai 后保存。
- 曲包傻瓜导入：把谱面压缩包拖进曲库文件夹，重启游戏即可，无需改配置。
- 占位曲进曲库：首次启动会把 Neon Drift 复制到曲库，和社区曲包一样管理。
- 游玩界面三档：初学者（大键帽/HUD）、普通、专业（隐藏键位提示）。
- 0.3 输入模式：键盘使用横向琴键布局；触摸屏使用八区多点触控。音符方向可设为从上往下或从下往上。默认音符可视时间 2.0 秒，可在设置里调慢/调快。
- Windows 触控板在 Electron 中只能作为单鼠标指针，无法读取八指同时触摸；触控板可点击/拖动回退，真正的八区多点需要触摸屏。
- UI：开放式主菜单（左侧文字菜单、右侧游戏名）、选曲难度色环、计分面板/连击环。
- 音频格式兼容：MP3、WAV、FLAC、M4A、AAC、OGG、Opus、WebM 可解码。
- 主页面/游戏背景：拖入照片 → 拖动选择区域、缩放 → 保存；支持 JPG/PNG/WebP/AVIF/GIF/BMP/SVG/HEIC。
- 游戏内按 Esc 唤出暂停菜单（继续/重试/返回主页面/选曲），再按 Esc 继续。
- 选曲页新增「主页」按钮，并统一放到左上角。
- 损坏曲包会被跳过并提示；导入/保存使用原子写入；外部页面/窗口被拦截。
- 便携版数据（曲库/user-data）保存在便携 exe 同级目录；标题/设置显示版本。
- 设置/自动打谱/结算的返回按钮统一放在左上角；游戏左上角新增可点击的「暂停」按钮。

------------------------------------------------
三、音频格式兼容
------------------------------------------------

可直接解码：
  MP3、WAV、FLAC、M4A（AAC）、AAC、OGG、OGA、Opus、WebM

平台下载的无加密 MP3/FLAC/M4A 可以直接用于自动打谱或曲包。

以下平台缓存是 DRM 加密格式，本项目不解密：
  网易云 .ncm
  QQ 音乐 .qmc0/.qmc3/.qmcflac/.mflac/.mgg
  酷狗 .kgm    酷我 .kwm    虾米 .xm

请先在对应平台内合法下载/导出无加密音频；加密文件会被检测并给出提示，
不会生成坏谱面。WMA/APE/AIFF 等不原生支持的格式请先转成 MP3 或 FLAC。

------------------------------------------------
四、操作
------------------------------------------------

默认键位把圆环从底部顺时针“展开”到键盘：

    A  S  D  F      J  K  L  ;
    5  6  7  8      1  2  3  4

  A = 下       S = 左下     D = 左       F = 左上
  J = 上       K = 右上     L = 右       ; = 右下

- Tap：音符到达判定环时按对应键。
- Hold：按住对应键，直到长条结束。
- Slide：先按起点键，再按顺序敲击路径上的路点键（路点旁有键帽提示）；
  如果太难，可在设置里改成“自动滑条”。
- Touch：菱形音符，按对应扇区的键。
- Break：橙色大音符。

菜单：
- 标题：Enter / 空格 开始；C 自动打谱；B 更换背景；S 设置；Esc 退出。
- 选曲：↑↓ 选歌；←→ 难度；Enter 开始；Esc 返回标题；S 设置；C 自动打谱。
- 游戏中：Esc 暂停/继续；F11 全屏。
- 结算：Enter 再来一次；R 回放本局（手动游玩）；Esc 选曲；T 标题。

换背景（主页面 / 游戏内）：
- 标题按 B 或点「背景」，也可以直接把照片拖到标题窗口。
- 游戏内把照片直接拖进窗口：会先暂停，再打开裁切器。
- 在裁切器中拖动画面选择构图，滚轮/滑杆缩放，保存后自动记住。
- 设置 → 显示与声音 → 主页面背景 / 游戏背景，可重新选择或恢复默认。
- 支持 JPG、PNG、WebP、AVIF、GIF、BMP、SVG、HEIC/HEIF；
  TIFF 等格式请先转成 JPG/PNG/WebP。GIF 只取第一帧。

------------------------------------------------
五、游玩界面三档
------------------------------------------------

设置 → 显示与声音 → 游玩界面：

- 初学者：键位提示放大、圆形键帽、计分/连击更大。
- 普通：默认键帽与 HUD。
- 专业：隐藏键位提示，弱化轨道和扇区，缩小 HUD。

“键帽提示”复选框可以额外关闭提示；专业模式始终隐藏。

输入方式（设置 → 显示与声音）：

- 键盘（横向琴键）：八个按键按 A S D F J K L ; 横向展开，键位在屏幕中下部
  （音符方向“从下往上”时在中上部），音符落向判定线。
- 触摸屏（八区）：圆环拆成八个扇区，每个扇区都是触控命中区；支持多点同时按。
- 音符方向：键盘琴键布局可选择从上往下或从下往上。
- 触控板：Windows 只暴露单个鼠标指针，不能用八个手指同时按；触控板可当作
  单指回退（移动指针 + 点击/拖动），完整的八区多点请使用触摸屏。

------------------------------------------------
六、延迟校准（建议第一次玩之前做）
------------------------------------------------

设置 → 延迟校准 → 跟着节拍按空格 12 次 → 应用。

- 音乐整体比画面慢/快 → 调“音频偏移”。
- 按键总被判早/晚 → 校准“输入偏移”。
- 蓝牙耳机/音箱延迟通常较大，务必校准。

------------------------------------------------
七、添加社区曲包（傻瓜模式）
------------------------------------------------

选曲页点「导入曲包」，或打开：

安装版：%USERPROFILE%\Documents\MaimaiKey\content
便携版：<便携版exe目录>\content

把谱面压缩包（.zip）直接拖进去，重启游戏即可。

支持：
1. 已整理好的内容包：zip 里有 pack.json + charts/ + audio/；
2. 社区 maidata 包：zip 里有 maidata.txt + 音频（MP3/WAV/FLAC/M4A/AAC/OGG 等）+ 可选封面。

启动时自动解压、转换并删除 zip；失败原因在 .failed 文件夹。
也可以直接放已解压的包文件夹（必须有 pack.json）。内置占位曲也在
content/starter/，可以查看或替换；删除后会回退到安装包内置版本。

请只使用你有权使用的音乐与谱面。

------------------------------------------------
八、音频自动打谱（CHART LAB）
------------------------------------------------

标题界面按 C，或选曲页「自动打谱」。

1. 拖入/选择 MP3、WAV、FLAC、M4A、AAC、OGG、Opus、WebM；
2. 自动检测 BPM；如不准，手动填 BPM 后重新生成；
3. 调密度、音频偏移，选择是否加入长按/滑条/触摸；
4. 生成四张谱面，右侧可直接编辑 Simai 文本；
5. 点「保存到曲库并返回」，新曲会出现在选曲列表。

生成的是可玩的草稿，不是人工谱；建议按音乐试玩后微调。
也可以「导出 .simai」单独保存。

------------------------------------------------
九、设置、成绩与回放
------------------------------------------------

- 设置、成绩、回放保存在：
  安装版：%APPDATA%\maimai-key
  便携版：<便携版exe目录>\user-data
- 重置设置/成绩/回放：关闭游戏后删除对应文件夹
  （曲库不受影响）。
- 手动游玩结束自动保存回放（最近 20 局），结算页按 R 观看。
- AUTO 演示不计成绩、不保存回放。

------------------------------------------------
十、常见问题
------------------------------------------------

Q：双击没反应 / 闪退？
A：确认是解压后运行、整个文件夹完整；更新显卡驱动；
   关闭录屏、悬浮窗、RGB/游戏覆盖层后重试。

Q：没有声音？
A：先点一下游戏窗口（浏览器音频需要一次用户操作才能启动）；
   检查 Windows 输出设备和音量；蓝牙设备请重新校准。

Q：黑屏？
A：更新显卡驱动；关闭其他占用 GPU 的程序后重试。

Q：按键冲突、同时按多个键丢键？
A：普通办公键盘通常只有 6 键无冲；建议 N-Key Rollover 键盘，
   或在设置里重新分配键位。

Q：导入的曲包没出现？
A：确认 zip 放在 content 根目录、游戏完全退出后重启；
   查看 content/.failed 里的失败原因；确认包内有 pack.json
   或 maidata.txt + 音频。

Q：自动打谱 BPM 不准？
A：在 CHART LAB 里手动填写正确 BPM，再点“分析并生成”。

Q：按 F12 没有开发者工具？
A：发布版刻意关闭了 DevTools（F12、Ctrl+Shift+I/J/C 和默认菜单都不生效），
   防止误触或改动游戏状态；这是正常行为。

Q：SmartScreen 拦截？
A：这是未签名程序的正常提示，点“更多信息 → 仍要运行”。
